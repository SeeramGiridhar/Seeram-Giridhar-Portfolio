# Seeram Giridhar — Professional Portfolio

A responsive, recruiter-focused static portfolio built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — semantic page structure, SEO metadata, JSON-LD profile data.
- `styles.css` — responsive dark-tech visual system, cards, timeline, mobile navigation styling.
- `script.js` — mobile menu + lightweight reveal animations.
- `Seeram_Giridhar_Resume.pdf` — resume download used by the website.

## Run locally
Open `index.html` directly in a browser, or run a simple local server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy
This is a static site, so it can be deployed to GitHub Pages, Netlify, Vercel, or Cloudflare Pages.

## Notes
- Project links point to the GitHub repositories provided in the resume.
- No live-demo URL is invented where the resume does not provide one.
- The contact section uses email/phone/social links and does not require a backend.
